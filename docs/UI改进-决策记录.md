# UI 改进 · 决策记录（2026-10-18）

> 对照对象：《记账本 v1.11.0》（Capacitor/WebView），拆解见 `docs/` 外部分析文档。
> 本文只记「改了什么、为什么、开关在哪」，方便后面回看。

## 结论：只借信息组织，不借视觉体系

两边设计语言几乎同源（主文字 `#14181D` vs `#14161A`、大数字都是 34px/600、卡片圆角 16），
所以**基础视觉一点没动**。抄的是「同一个信息怎么给得更省事」。

没做：月份条「回到本月」、金额输入闪烁光标（都列为"暂时不改"）。

## 两个实验开关（D-03 与空态文案）

`lib/data/ui_flags.dart`，默认全开。想关掉不用重编，往 `setting` 表插一条：

```sql
-- 关掉类型 chips
INSERT OR REPLACE INTO setting(k, v) VALUES('ui.type_chips', '0');
-- 关掉空状态第二行引导
INSERT OR REPLACE INTO setting(k, v) VALUES('ui.empty_hints', '0');
```

下次启动 `Store.boot()` 会读到。定下来之后，把 `UiFlags` 里那一项删掉、
调用点的 `if` 去掉，只留一种行为即可。

## 明确不抄

- **支出红 / 收入绿 / 转账蓝**：和「红色只表示超支」直接冲突，抄了警示就失效
- **分类彩色 + 12% 透明底**：破坏黑白灰，灰阶饼图是有意设计
- **WebView + localStorage**：5 MB 上限、同步 API 卡主线程
- **480px 居中 + 桌面投影**：纯移动端不需要

## 顺带修掉的越界

- hero 的「收入 / 结余」行：金额到五位数 + 带符号会挤出卡片（改用 Expanded + FittedBox）
- 按日分组的日期头：某天既有收入又有支出时右侧被裁（日期改 Expanded + ellipsis）
