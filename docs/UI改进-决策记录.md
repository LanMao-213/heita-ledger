# UI 改进 · 决策记录（2026-10-18）

> 对照对象：《记账本 v1.11.0》（Capacitor/WebView），拆解见 `docs/` 外部分析文档。
> 本文只记「改了什么、为什么、开关在哪」，方便后面回看。

## 结论：只借信息组织，不借视觉体系

两边设计语言几乎同源（主文字 `#14181D` vs `#14161A`、大数字都是 34px/600、卡片圆角 16），
所以**基础视觉一点没动**。抄的是「同一个信息怎么给得更省事」。

没做：月份条「回到本月」、金额输入闪烁光标（都列为"暂时不改"）。

## 两个实验开关（D-03 与空态文案）

`lib/data/ui_flags.dart`，默认全开。想关掉不用重编，往 `setting` 表插一条：

```sql
-- 关掉类型 chips
INSERT OR REPLACE INTO setting(k, v) VALUES('ui.type_chips', '0');
-- 关掉空状态第二行引导
INSERT OR REPLACE INTO setting(k, v) VALUES('ui.empty_hints', '0');
```

下次启动 `Store.boot()` 会读到。定下来之后，把 `UiFlags` 里那一项删掉、
调用点的 `if` 去掉，只留一种行为即可。

## 明确不抄

- **支出红 / 收入绿 / 转账蓝**：和「红色只表示超支」直接冲突，抄了警示就失效
- **分类彩色 + 12% 透明底**：破坏黑白灰，灰阶饼图是有意设计
- **WebView + localStorage**：5 MB 上限、同步 API 卡主线程
- **480px 居中 + 桌面投影**：纯移动端不需要

## 顺带修掉的越界

- hero 的「收入 / 结余」行：金额到五位数 + 带符号会挤出卡片（改用 Expanded + FittedBox）
- 按日分组的日期头：某天既有收入又有支出时右侧被裁（日期改 Expanded + ellipsis）

## 2026-10-18 · 真机反馈的第二轮

| # | 决定 | 说明 |
| --- | --- | --- |
| D-09 | 概览卡改**浅灰**（`C.bg2` + 描边） | 原来的纯黑 hero 在满屏黑白灰里太重，一进页面只剩一块黑。浅灰是「压下去」的汇总区 |
| D-10 | 明细按日**成卡**：日期头移进卡内 | 白卡叠白底只靠 1px 描边，读起来仍是一条长列表；加 4% 投影 + 卡内日期头，分组才成立 |
| D-11 | 明细顶部**不提供翻期**，只有「当前期 + 日历」 | 一期跨两个月，左右箭头一次挪一期、翻远了还得数；点日历直接跳 |
| D-12 | 日历改**上下滚动**，取消左右翻月 | 时间铺成一条线，一次滑动跨半年；`PageView` 式的翻月每翻一次都要重新定位 |
| D-13 | 记一笔**去掉「完成」按钮** | 输入法自带的「完成」、收起键盘、点空白处，三种都是「写完了」；面板不再为它多长一层 |
| D-14 | 数字键盘**按可用高度算键高**，并让出系统手势条 | 之前 46dp 固定高 + 不扣 `viewPadding.bottom`，真机上最后一排（0 / . / 确认）被裁掉一条 |

净值仍然只在「我的」页；首页的定位是「这一期花了多少」，不承担资产总览。
| D-15 | 键盘改成**单一 4 列网格**（`keyW = (W-3g)/4`） | 之前上面 4 个 `Expanded`、下面 `flex 3:1`，两套算法算出 87 / 86 / 90 三种宽度：「3 / .」偏左、确认比「+」宽。现在所有键（含确认、含「0」跨格）都按同一个 `keyW` 排 |
| D-16 | 键盘**视觉重做**：数字去底色、运算符留淡底、C/⌫ 浅字、确认是唯一重色块 | 12 个灰块让视觉重量全压在「键」上，金额反而被埋掉；去底色后数字放到 23px，读数更快。按下统一浮出 `C.line`（无底色键没反馈就像没点着）。键位表抽成 `CalcKeySpec` 数据，加键/跨格只改一行 |
| D-17 | 键盘**所有键统一底色**（`bg2`），按下压到 `line2` | 上一版把数字做成无底、运算符留底，键盘看起来像两套东西拼的，也看不清一个键到哪儿为止。要么全铺底、要么全不铺用短线段隔开 —— 选前者：铺底同时给出点击面范围。区分靠字号与字色（数字 23 / 运算符 21 / C·⌫ `ink2` 17），不再靠填色分档。测试里钉死「不许有 transparent」 |
| D-18 | 键高 46 → **56**（用户从四版里选 D） | 46 在 390dp 宽屏上纵向余量紧，尤其「确认」竖跨两行时贴着「0」那排。四版对比（46/50/52/56）后选最高一档；上限抬到 56 后矮屏仍按 `(可用高-380)/5` 往下收，下限 38 不变，不会裁掉「确认」 |
