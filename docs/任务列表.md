## 0. 使用约定

**阶段门禁（每阶段结束必须全绿，否则不进下一阶段）**

1. `flutter analyze` → 0 error / 0 warning
2. `env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy NO_PROXY=localhost,127.0.0.1 flutter test --exclude-tags golden` → 全绿
3. `C:/src/flutter/bin/flutter build apk --debug` → 出包成功
4. 三个门禁脚本 `tools/check_no_network.sh` / `check_theme_hardcode.sh` / `check_dead_public.sh` → 退出码 0

**任务粒度规则**

- 一个任务 = 一层/一个功能模块的一组文件，**至少 3 个文件**；不拆单文件任务。
- 配置文件只在 **T00-1** 一次性建完，后续任务不再碰 `pubspec`/`gradle`（除 T06-3 出包签名）。
- 数据层（阶段 1）必须先于任何 UI 任务：UI 不许"顺手写 SQL"。
- `T-` 编号即执行序号；**依赖为空 = 可与同阶段其它任务并行**。

**签名纪律**：`android/key.properties` 与 `*.jks` **永不进仓库、永不写进文档正文**。T06-3 的出包脚本只从环境变量/`-P` 注入路径与口令。
