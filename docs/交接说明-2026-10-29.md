## 1. 这一轮做完了什么

### 1.1 可收起的侧拉栏（`lib/pages/app_drawer.dart`，新建）

`Scaffold.drawer`，五组十九个入口，任何页面一次手势可达（左边缘右滑，或点页头最左三横）：

| 组 | 入口 |
| --- | --- |
| 常用 | 记一笔、转账 |
| 导航 | 明细、图表、计划、我的 |
| 管理 | 账户管理、分类管理、账本管理、记账模板、周期账单、账单日 |
| 数据 | 导出 Excel、加密备份、明文备份、从备份恢复、数据安全 |
| 帮助 | 使用引导、帮助说明 |

- 组标题可点，收起后子项**真的从树上移除**（不是 `Offstage`），箭头随 `AnimatedRotation` 转 90°。
- 当前页在「导航」组留墨色竖线 + 加粗；顶部「当前账本 · xxx」，底部常驻「不联网 · 数据只在这台设备上」+ 版本号。
- 四页页头统一挂 `MenuButton`（`lib/widgets/common.dart`）；「我的」页原来的品牌标志移到抽屉顶部。

### 1.2 首次使用引导（`lib/pages/onboarding_page.dart`，新建）

五步：欢迎（数据只在本地）→ 记一笔（底部 ＋、四档类型、账单日）→ 侧拉栏（左滑或三横、分组可收）→ 明细与图表（概览卡左右滑翻期）→ 数据在你手里（换机先导出备份）。

- 跳过 / 上一步 / 下一步 / 系统返回键；**走完或跳过都算看过**。
- 判据：`Db.createdNow`（sqlite `onCreate` 置位的「这次是新建库」）**且** `setting` 表无 `onboarding.done`。
- 侧拉栏 →「使用引导」随时重看，重看**不看标记**。

### 1.3 帮助说明页（`lib/pages/help_page.dart`，新建）

六节（记账 / 三个页面 / 侧拉栏 / 数据 / 隐私 / 常见问题），独立页 + `AppBar` 返回，仿 `safety_page.dart`。刻意只写**已成立的行为**，每条都能在代码里找到落点。

## 2. 关键决策（含放弃的方案）

| # | 决策 | 理由 / 放弃的方案 |
| --- | --- | --- |
| D1 | 抽屉动作**排在 `closeDrawer()` 之后**执行（`Future.delayed(M.base)`），且在**宿主 context** 上跑 | 直接执行会让新页面从没收完的抽屉上方压过去，返回时抽屉还开着；抽屉子树收起即销毁，捕获抽屉自己的 context 会炸 |
| D2 | 分组**收起状态只记内存，不落库** | 它是「这会儿不想看这组」的临时偏好，为它加设置键不值当，也不该出现在备份文件里 |
| D3 | 引导判据用**双条件**（`Db.createdNow` **且** 无标记） | 只看标记 → 用了半年的老用户升级会被塞一份；只看新建 → 清空数据重建库也会弹 |
| D4 | `finishOnboarding()` 落库**不 await**，`pop` 立刻执行 | `await` 真 I/O 会让假时钟下的 widget 测试永久挂起（这一坑排查了 6 轮），且用户没必要为写一个标记等一帧 |
| D5 | 测试里关 `Onboarding.autoShow`，而非改判据 | 整屏遮罩会盖住几十条无关用例的操作目标；关自动、不关功能 |
| D6 | 1.7.0 发布后发现布局问题 → **升 1.7.1**，不改 `v1.7.0` | 同一个版本号必须是同一份字节。已发布的标签只读 |
| D7 | **不压缩 `.so`**（刻意不做） | 改 deflate 能让 APK 再小约 8 MB，但安装时要解出来，**安装体积反而变大**，还失去 mmap 共享页、冷启动更慢 |
| D8 | 设置动作抽成 `settings_actions.dart` 的公开函数，而不是 `import` 一个 page | 否则侧拉栏要么依赖页面，要么把这批 SQL / 文件选择 / 二次确认再抄一遍——「清空」这类动作措辞差一句就是数据事故 |
| D9 | 在 `C:/hb/hl`（中性路径）构建 | 直接把本机用户名路径写进产物与堆栈 |
| D10 | 引导内容改**垂直居中**（`LayoutBuilder` + `ConstrainedBox(minHeight)` + 仍套 `SingleChildScrollView`） | 原版贴顶、下方空出约 340dp，像没加载完；保留可滚是为了大字号 / 横屏时不把按钮挤出屏幕 |

## 7. 注意事项

1. **本机跑测试要先摘代理**，否则全是「无法连接 flutter_tester」（见第 4 节）。
2. **已发布的标签只读**。发现界面问题就升版本号重发，不要 `git tag -f`。
3. **加/删 `test/*.dart` 必须同步 README 的「N 个测试文件」**，`docs_facts_test` 会断言。
4. **真机上覆盖安装只能用 debug 签名包**，放进 `release.jks` 会变成正式签名、只能卸载重装。
5. **抽屉里的动作必须在宿主 context 上跑**，新增入口照 `_run()` 的写法抄，别自己在 `build` 里捕获 context。
6. **测试里点抽屉入口要多 pump 一次**：`tap` → `pump(320ms)` → `pumpAndSettle`（`Future.delayed` 是纯定时器，`pumpAndSettle` 不会为它继续 pump）。
7. **`finishOnboarding` 落库不要改回 `await`**，否则 widget 测试会挂到超时。
8. 产物 96% 是 Flutter 引擎 + AOT 产物，再想显著减小只能自编译引擎，性价比很低——体积这条线基本到此为止。
