黑塔 Bookkeeping Icon Set · 66 枚 · 24×24 描边网格

面向记账软件的简约线性图标集。视觉母题取自漫画《血族Bloodline》中的超自然势力 极黑之塔—— 藏书塔、法术书、符文、法阵，翻译成流水、预算、报表这些财务语义。 全部为 24px 网格、1.75px 等宽描边、圆头圆角，纯 currentColor 单色。 已按要求移除 账簿、快捷记账、语音记账（邪口）三枚，描边为 1.75；画风版中的账簿与邪口题材也已一并删除。

接入方式

方式一：直接引用单个文件，颜色随 color 变化。

<span style="color:#14161B">
  <img src="icons/category/food.svg" width="24" height="24" alt="餐饮">
</span>

方式二：引入 sprite.svg，用 <use> 复用（推荐，一次加载全站可用）。

<svg class="icon"><use href="sprite.svg#bt-food"></use></svg>

.icon { width:24px; height:24px; fill:none; stroke:currentColor;
        stroke-width:1.75; stroke-linecap:round; stroke-linejoin:round; }
  • sprite 内 id 统一为 bt-<文件名>，如 category/food.svg → #bt-food。
  • 点任意图标卡片可复制其英文键名。
  • 需要实心（filled）版本时，同一 24 网格上重绘填充路径即可，本套仅提供线性版。
