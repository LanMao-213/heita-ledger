三、安装流程（共 8 步）

1

先配国内镜像（重要，先做这步）

镜像配在前面，后面所有下载都会走国内节点。打开 PowerShell（不是 cmd），逐行执行：

[Environment]::SetEnvironmentVariable("PUB_HOSTED_URL", "https://pub.flutter-io.cn", "User")
[Environment]::SetEnvironmentVariable("FLUTTER_STORAGE_BASE_URL", "https://storage.flutter-io.cn", "User")
为什么用 PowerShell 而不是 setx：setx 有 1024 字符的长度限制， 写 PATH 时可能把已有内容截断。上面的写法更安全，且只影响当前用户、不需要管理员权限。

验证（应回显两个地址）：

$env:PUB_HOSTED_URL
$env:FLUTTER_STORAGE_BASE_URL
注意：环境变量设好后必须新开一个终端窗口才会生效，当前窗口读不到。
2

下载并解压 Flutter SDK

用国内镜像直接下载（原版地址太慢）：

https://storage.flutter-io.cn/flutter_infra_release/releases/stable/windows/flutter_windows_3.47.7-stable.zip

想确认有没有更新的版本，可以打开版本清单查 current_release.stable 字段：

https://storage.flutter-io.cn/flutter_infra_release/releases/releases_windows.json

解压位置有讲究

必须放在没有空格、没有中文的路径下，且不要放 C:\Program Files。
原因：Flutter 的构建脚本和 Gradle 处理带空格的路径会出错；Program Files 还有写入权限问题。

推荐解压到：C:\src\flutter，最终结构应该是：

C:\src\flutter\
├── bin\          ← 里面是 flutter.bat
├── packages\
├── dev\
└── ...

在 PowerShell 里一条命令搞定下载 + 解压：

New-Item -Path "C:\src" -ItemType Directory -Force
cd C:\src
Invoke-WebRequest -Uri "https://storage.flutter-io.cn/flutter_infra_release/releases/stable/windows/flutter_windows_3.47.7-stable.zip" -OutFile "flutter.zip"
Expand-Archive .\flutter.zip -DestinationPath .
Remove-Item .\flutter.zip
3

把 Flutter 加进 PATH

$p = [Environment]::GetEnvironmentVariable("Path","User")
[Environment]::SetEnvironmentVariable("Path", "$p;C:\src\flutter\bin", "User")

然后关掉 PowerShell 重新打开，验证：

flutter --version

看到类似 Flutter 3.47.7 · channel stable 就成功了。

4

安装 Android Studio

国内镜像地址（比官网快很多）：

https://developer.android.google.cn/studio

安装时保持默认选项即可。装完后首次启动会走一遍设置向导，选择 Standard（标准）， SDK 会自动下载到默认位置：

C:\Users\<用户名>\AppData\Local\Android\Sdk

这一步会下载 Android SDK 主体，是全程最耗时的一步，让它自己跑完。

5

补齐 SDK 组件

Android Studio → 右上角 More Actions → SDK Manager，确认这几项已勾选并安装：

标签页组件
SDK PlatformsAndroid 16 (API 36) 或 Android 15 (API 35)
SDK ToolsAndroid SDK Build-Tools
SDK ToolsAndroid SDK Platform-Tools
SDK ToolsAndroid SDK Command-line Tools ← 这个最容易被漏，漏了 Flutter 会报错

勾完点 Apply 等下载完成。

6

接受 Android 许可协议

新开 PowerShell，执行：

flutter doctor --android-licenses

会连续问很多条，一路按 y 加回车接受即可。

7

给 Android Studio 装 Flutter 插件

Android Studio → File → Settings → Plugins → Marketplace，搜索 Flutter， 点 Install（会连带自动装 Dart 插件），装完重启 Android Studio。

8

总检

flutter doctor -v

理想结果是这样，每一项前面都是 [✓]：

[✓] Flutter (Channel stable, 3.47.7, on Microsoft Windows 10)
[✓] Windows version (Windows 10 or higher)
[✓] Android toolchain - develop for Android devices (Android SDK 36.0.0)
[✓] Android Studio (version 2025.x)
[✓] Connected device (1 available)

下面这些出现也正常，不影响我们做 Android：

  • [✗] Visual Studio — 不做 Windows 桌面应用，忽略
  • [!] Android Studio (not installed) — 说明 Flutter 没找到 Android Studio 路径， 执行 flutter config --android-studio-dir="C:\Program Files\Android\Android Studio" 指定一下

四、连接真机

手机上

  1. 设置 → 关于手机 → 连续点击「版本号」7 次，提示「您已进入开发者模式」
  2. 返回设置 → 系统 → 开发者选项 → 打开 USB 调试
  3. 用数据线连电脑 —— 注意必须是数据线，很多充电线只能供电、传不了数据
  4. 手机上会弹出「允许 USB 调试吗」，勾选「始终允许」并确定

电脑上验证

adb devices
# 应看到一行设备号 + device，例如：
# 8A3KX19B2000xxxx    device

flutter devices
# 应列出你的手机

五、创建工程验证（最后一步）

全部装完后，跑一个空白工程确认整条链路通了：

cd C:\Users\<用户名>\WorkBuddy\2026-10-16-09-53-46
flutter create --platforms=android --org com.example ledger_smoke_test
cd ledger_smoke_test
flutter run
这里只是验证环境用的临时工程，包名用 com.example 占位就行，验证完可以删掉。
正式项目的包名会用中性命名（不绑定品牌名，这样以后改 App 名字不用动包名）， 具体叫什么在正式建工程时我会给你，不用现在操心。

如果应用能在你手机上跑起来，环境就算通了。

六、常见问题排查

症状原因与处理
flutter 命令找不到环境变量没生效。关掉终端重新开一个。还不行就检查 C:\src\flutter\bin 是否真的在 PATH 里
flutter pub get 卡住不动镜像没生效。新开终端执行 echo $env:PUB_HOSTED_URL 确认有值
Gradle 下载极慢见下方「Gradle 加速」
flutter doctor 报 Android license 未接受执行 flutter doctor --android-licenses，一路 y
报 cmdline-tools component is missing第 5 步漏了 Command-line Tools，回 SDK Manager 补装
构建报路径过长错误执行 git config --system core.longpaths true（需管理员权限的终端）
真机连不上、adb devices 为空依次排查：USB 调试开了吗 → 是不是充电线 → 手机上有没有点「允许」→ 换一个 USB 口
在 Android Studio 里跑不了 Flutter 项目第 7 步的 Flutter 插件没装或没重启 IDE

Gradle 加速（建议做，能省很多等待）

Flutter 项目的 Android 侧依赖 Gradle，默认从国外下载会很慢。等我们建好正式工程后，我会在 android/build.gradle 里加上阿里云镜像仓库、并在 gradle-wrapper.properties 里 把 Gradle 发行包换成腾讯镜像 —— 这两处建工程时我会直接配好，你不用管。
