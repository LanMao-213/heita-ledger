# 真机验收交接说明 — 2026-10-24

给拿到包的人：**照着这份单子过一遍，勾完把结果发回来**。不需要装开发环境，
只要一台 Android 手机和一根能传文件的线。

---

## 0. 一句话背景

这一版有两类改动：**六套主题可以在 App 里切换**、**所有二级/三级菜单重做了**。
自动化测试把数值（对比度、缩进、行高、颜色来源）都钉住了，**405 条全绿**，
但守不住「手感」和「真机屏幕上的观感」。所以下面这些必须人来点。

版本号**没有升**，仍是 `1.4.21+22` —— 是维护者有意等的，真机过了再一起升。

## 1. 环境要求

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| 手机 | **Android 8.0（API 26）以上，arm64 机型** | 包只打了 arm64。装在 32 位机器上会起不来 |
| 装机方式 | **覆盖安装**：直接装，不要先卸载 | 包用的是正式密钥 `CN=Heita Ledger`，和已装的 1.4.21+22 / 1.4.6+14 同一个证书 → 覆盖安装**账目数据不动** |
| 如果想干净测 | 先 `我的 → 备份全部数据` 导出 JSON留底，再卸载重装 | 覆盖安装不丢数据，但留个底总没坏处 |
| 屏幕 | 建议**素质好一点**的屏（OLED/高分屏） | 这一轮主要看「白卡压在灰底上立不立得住」，低端屏色偏大看不准 |
| 光线 | 至少在**室内正常光**和**户外强光**下各看一轮 | 深色主题在强光下才看得出层级塌没塌 |

不需要：Flutter SDK、Android Studio、电脑上的任何环境。

## 3. 测试步骤

### 第 1 步：装上先别动（5 分钟）

1. 装包，打开。**先确认账目还在**（如果你是覆盖安装的话）。
2. 首页滑一遍，四个 Tab（明细 / 统计 / 计划 / 我的）都点开。
3. 记一笔，随便记一条，确认明细里能立刻看到。
   → 这一步只要有一处不对，先停下来反馈，后面的不用做了。

### 第 2 步：六套主题逐套过（15 分钟）

`我的 → 偏好 → 主题`，从上到下一套一套点。每套看这四处：

- **首页概览卡**（顶部那块大的）和底下卡片之间，**还分得开吗**
- **明细页**的流水行：分类图标、金额、备注三层的字都看得清吗
- **统计页**的收入柱（浅色那根）：**看得见吗**
- 随便弹一个二级菜单（比如账户的 ⋯）：白卡浮在灰底上吗

特别留意两套深色：**黑塔 · 永夜**（出厂默认）、**血族 · 深红**。
这两套之前概览卡对页面底只有 1.04:1（基本等于没分层），本轮修了，
要确认修完**真的看得出分层**，而不是数字好看了、眼睛还是糊的。

另外**切主题的时候盯一眼**：应该是「唰」一下整套换掉，
不该出现「上半屏新皮肤、下半屏旧皮肤」或者闪一下黑屏。

### 第 3 步：菜单手感（10 分钟）

弹层这东西，截图看不出问题，得点。至少点这四处：

1. `我的 → 账户管理 → 任一账户 → ⋯`（三项的菜单，最后一项是红的）
2. `明细 → 任一流水 → 长按`（删除确认框）
3. `计划 → 任一目标 → ⋯`
4. `我的 → 数据安全 → 快照 → ⋯`（右上角那个，以前是个下拉菜单，现在改成弹层了）

每处确认：

- 弹层高度合理，不用滚就能看完
- 底部的「取消」是**单独一张卡**，和上面的菜单项分开
- 分割线**只到文字左边**（左边缩进一块），不是横穿一整行
- 点空白处 / 下滑能关掉
- 危险项（红的那个）点下去，确认框**直接盖在页面上**，不是盖在自己的菜单上

### 第 4 步：备份恢复闭环（10 分钟）— 唯一的功能性验收

```
① 我的 → 备份全部数据        （导出 JSON，记住文件名）
② 随便改一笔                  （比如给某条流水加 100 元，或新记一笔）
③ 我的 → 从备份恢复 → 选刚才那个文件
④ 看第 ② 步的改动是不是没了
```

> ⚠️ **第 ② 步千万不要用「清空全部数据」来制造差异。**
> 测试构建里那个入口会触发种子数据重灌，恢复完库里会多出 23 条演示流水，
> 看起来就像恢复失败 —— 这是构建特性，不是 bug，但会浪费你半小时。

### 第 5 步：P1 / P2 剩下的（20 分钟）

按第 2 节表格里的 6 ~ 13 条逐条点。这几条都是**回归确认**：
本轮改了底色和菜单，要确认没把别的地方碰坏。

## 4. 判合格 / 不合格

| 现象 | 判定 |
| --- | --- |
| 六套主题都能切、切完不闪、深色两套卡片看得出分层 | ✅ |
| 菜单弹层是「白卡浮在灰底上」，分割线只到文字左边 | ✅ |
| 危险项是红字、和同组其他项在一张卡里 | ✅ |
| 记一笔 / 备份恢复 / 图表数字都对 | ✅ |
| 深色主题下概览卡和底色**糊在一起分不开** | ❌ 报回来，说清是哪一套 |
| 切主题时闪黑屏、或出现半新半旧 | ❌ 报回来，说清从哪套切到哪套 |
| 任何一处**溢出**（文字撑破卡片、右侧挂黄黑条纹） | ❌ 截图报回来 |
| 弹层里点某项，弹出框压在自己的菜单上 | ❌ 报回来，说清哪个入口 |

## 5. 反馈要带什么

报问题时请带上这四样，缺一样就得来回问：

1. **哪个入口**（一步步怎么点到那儿的）
2. **哪套主题**（六套里的哪一套 —— 深色两套是重点嫌疑）
3. **截图**（问题界面 + 上一屏，各一张）
4. **机型 + Android 版本**（设置 → 关于手机）

---

## 6. 几条别踩的坑

- **不要用「清空全部数据」做测试**（原因见第 3 步第 ④ 条）。
- **32 位（armeabi-v7a）老机器装不了**这个包，别浪费时间试。
- **卸载重装会清空账目** —— 要干净测就先备份。
- 包里**没有**演示数据（那 23 条种子只在「清空全部数据」后才会出现），
  第一次打开是空的，这是对的。
