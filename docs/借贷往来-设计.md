# 借贷往来 + 模板子分类 · 设计（1.3.0）

> 状态：**已确认**（2026-10-19 逐项确认，见文末「确认记录」）。目标版本 **1.3.0**，schema **v6 → v7**。
> 依据：2026-10-19 讨论，用户已定「独立债务记录」模型；1.2.0 不单独发，与借贷一起出包。

---

## 一、需求（按你的原话整理）

1. 借出去一笔钱：从某个账户出去，**这笔支出不计入本周期预算**
2. 收回一笔借款：**不计入本周期收入**
3. 借进来一笔钱：**可以选择是否计入本期预算**
4. 要能查：找谁借了多少、借给谁多少、我什么时候该还、对方什么时候该还我
5. 这些查询放在**专门的卡片**里

对应到数据上，其实要三样东西：**不影响预算** + **知道对方是谁** + **知道什么时候该还**。所以底下必须有「一笔借贷」这个实体，光靠交易上的几个字段算不出「这笔还没还」。

---

## 二、数据模型

### 新表 `debt`（一笔借贷 = 一条记录）

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | INTEGER | 主键 |
| `direction` | TEXT | `out` 借出（别人欠我）/ `in` 借入（我欠别人） |
| `counterparty` | TEXT | 对方名字，必填 |
| `principal` | INTEGER | 本金，**分**（沿用全项目约定） |
| `account_id` | INTEGER | 资金从哪个账户进出 |
| `date` | TEXT | 发生日 `YYYY-MM-DD` |
| `due_date` | TEXT | 约定还款日，可空 |
| `count_in_budget` | INTEGER | 借入时是否计入本期可用，默认 0 |
| `closed_at` | TEXT | 结清时间，`NULL` = 未结清 |
| `note` | TEXT | 备注 |
| `created_at` | TEXT | 创建时间 |

**已还多少、还剩多少都不存**，按关联流水实时算：`剩余 = principal − Σ还款流水`。存冗余字段就会和流水对不上。

### `txn` 加一列

```sql
ALTER TABLE txn ADD COLUMN debt_id INTEGER;   -- 可空，普通账目为 NULL
```

### 为什么不新增一种交易类型

你的选择是「应收/应付」这个语义，但落到代码里，**不扩 `TxnType` 枚举**（现在只有 支出/收入/转账），而是用 `debt_id` 标记：

- 账户上的效果本来就是「钱出去了 / 钱进来了」，`expense` / `income` 完全够用；
- 扩枚举要改所有 `switch (type)` 的地方：明细分组、筛选器、Excel 类型列、统计、周期归集、备份，一处漏掉就出错；
- 用 `debt_id != null` 判断，**明细里照样显示「借出 · 张三」、金额用中性灰而不是红**，统计照样排除，外观和「新类型」没有区别，改动面小一半。

## 三、四条口径（这里需要你点头）

### 1. 支出统计：借贷流水全部排除

所有借贷产生的流水 `debt_id` 非空，统计查询统一加 `WHERE debt_id IS NULL`。**过滤写在 `Repo` 层**，不让每个页面自己判断 —— 六个页面各写一遍，漏一个就有一个数字错。

### 2. 账户余额：照常增减

借出 5000，现金账户就少 5000。这是事实，不做特殊处理。

### 3. 总资产：账户余额 + 应收 − 应付

如果只减账户余额，借出 5000 会让「我的」页总资产凭空少 5000，看起来像钱丢了。所以在总资产下面多两行：**应收 ¥5000 / 应付 ¥0**，总资产 = 账户合计 + 应收 − 应付，借出前后不变。

### 4. 预算：借出/收回不计入；借入按开关

- 借出、收回：一律不进本期可用、不进收入
- 借入且 `count_in_budget = 1`：**本期可用金额加上这笔本金**，预算卡上标一行「含借入 ¥3000」；**预算额度本身不改**（仍是你设的那个数），下个月自动恢复
- 借入且开关关闭：只动账户余额，预算完全不看它

## 四、界面

### 1. 记一笔面板

类型切换从「支出 / 收入 / 转账」变成 **支出 / 收入 / 借出 / 借入**（转账原本就不在这个面板里，它在账户页）。

选「借出」或「借入」后，面板多出：

- **对方**（必填，输入框，带历史名字联想）
- **应还日**（选填，日期选择）
- 「计入本期预算」开关（只在借入时出现，默认关）

分类轮盘、备注、键盘照旧。借出/借入仍然可以从某个账户出钱，所以账户选择保留。

### 2. 往来卡片（计划页顶部）

「计划」页（预算 / 储蓄）顶部一张摘要卡：**应收 ¥X / 应付 ¥Y / 本月到期 Z 笔**，点进去是完整列表。

> 放这里而不是「我的」，是因为借贷直接改变可用资金，和预算在同一个页面最容易被看到；放进「我的」就要点三层才想起来看。

列表按「未结清优先、到期日近的在上」排序，每行：

```
张三          借出 ¥5,000     应还 11-30   剩 ¥3,000  [未结清]
李四          借入 ¥2,000     应还 10-25   剩 ¥2,000  [逾期 3 天]
```

点某条 → 详情：本金、已还流水、剩余、备注；底部两个按钮：**记一笔还款** / **标记结清**。

「记一笔还款」弹小面板：金额（默认剩余）、账户、日期 → 生成一条反向流水（`debt_id` 指向它），自动更新剩余；剩余归零自动 `closed_at`。

### 3. 明细页

借贷流水照常出现在明细里（不然查不到），但：

- 标签显示「借出 · 张三」「借入 · 李四」
- 金额用**中性灰**，不用支出的红、也不用收入的绿
- 副行显示「应还 11-30」

### 4. 账户页

账户余额不变。转账入口不动。

## 五、模板与周期账单的子分类

现状：`templates_page.dart:316`、`recurring_page.dart:110` 用的是 `expenseCats` / `incomeCats`（只有一级），所以「每月房租」只能挂「居家」，挂不到「居家/房租房贷」。

改动：这两处换成和记一笔同一个双轮盘 `showCategoryWheel`，数据层不用动（`category_id` 本来就能存子分类 id）。

**不加详情字段**：模板只还原「分类 + 金额 + 备注」，加四个详情列会让模板表结构跟着膨胀，收益低。

## 八、验收标准

1. 借出 5000 → 本月支出**不变**、账户余额 **−5000**、往来卡片显示「张三 欠 5000」、总资产**不变**
2. 部分还款 2000 → 剩余 3000、产生两条流水、支出统计仍不变、剩余归零后自动结清
3. 借入 3000 开「计入预算」→ 预算页可用金额 +3000 并标注「含借入」；关掉则不变
4. 逾期：应还日早于今天且未结清 → 列表标红并显示逾期天数
5. 模板选「居家/房租房贷」→ 保存后一键填充能还原到子分类
6. 周期账单挂子分类 → 到期自动补记的那笔落在子分类上
7. Excel 导出→导入一圈，借贷数据不丢；v6 旧备份恢复后不报错
8. `flutter analyze` 0 issue，`flutter test` 全绿，截图基线覆盖往来卡片

## 九、风险

1. **统计过滤漏点**：支出/收入出现在明细汇总、图表、预算、周期归集至少四处，靠页面各写一遍必漏。统一收在 `Repo`，再加一条「借贷流水不进统计」的测试兜住。
2. **总资产口径**：不加应收/应付，借出后用户会以为钱少了。已在设计里补上，实现时要确保「我的」页三行都算对。
3. **还款金额校验**：不能超过剩余，也不能为 0；非法输入要在面板层拦住。
4. **备份兼容**：v6 备份没有 `debt` 表，恢复必须容错，不能让老备份恢复失败。
5. **工期**：2–3 天是「顺利」的估计，T5（往来卡片）和 T6（口径）各占半天以上。
